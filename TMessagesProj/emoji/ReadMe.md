
The emoji pack (src/main/assets/emoji.pack) is generated with
TelegramEmojiGenerator [1]. It replaces the upstream Apple emoji pack; the
builder scripts in this directory are upstream's and are not used for it.

It contains visual assets from Twemoji [2] and Noto [3].
